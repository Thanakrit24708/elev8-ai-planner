ภาพรวมสถาปัตยกรรม (System Overview): ระบบ ELEV8 AI Planner ทำงานในรูปแบบ Cloud-Integrated Hybrid Architecture เชื่อมต่อ Google Classroom เพื่อดึงการบ้านของนักศึกษา ส่งเข้าประมวลผลผ่าน n8n Workflow Automation และ AI Chat Completion API เพื่อวิเคราะห์แตกงานย่อยเป็นภาษาไทย จากนั้นซิงค์ข้อมูลลง Google Sheets โดยตรงแบบไม่ต้องพึ่งพา Local MySQL/XAMPP

2 ข้อมูลจำเพาะของ Model AI ที่ใช้ (AI Models Specification)

ระบบกำหนดโมเดลปัญญาประดิษฐ์สำหรับการวางแผนงานวิชาการ (Academic Project Planning) อย่างชัดเจนดังนี้:

2.1 โมเดลหลัก (Primary LLM Engine): OpenAI gpt-4o-mini

พารามิเตอร์ การกำหนดค่า (Configuration) และเหตุผล
Model Identifier gpt-4o-mini
ผู้พัฒนา OpenAI
Temperature 0.2 (ค่าต่ำเพื่อลดความเพ้อฝัน และเน้นผลลัพธ์ที่เป็นขั้นตอนตามหลักเกณฑ์วิชาการ)
Response Format {"type": "json_object"} (บังคับโครงสร้างเอาต์พุตให้อยู่ในรูป JSON ที่ถูกต้อง 100%)
ภาษาผลลัพธ์ ภาษาไทย (Thai Language) ทั้งชื่องานย่อย (task_title) และคำอธิบาย (description)
บทบาทการทำงาน 1. รับหัวข้อการบ้าน + คำอธิบาย + กำหนดส่งจริงจาก Classroom
2. แตกขั้นตอนการทำงานออกเป็น 3-7 ข้อย่อยเรียงตามลำดับ (Sequential Subtasks)
3. ประเมินเวลาทำงานที่สมเหตุสมผล (estimated_hours)
4. กำหนดระดับความสำคัญ (HIGH / MEDIUM / LOW) และคำนวณวันกำหนดส่งย่อย

2.2 โมเดลสำรอง (Fallback LLM Engine): Google Gemini 1.5 Flash

พารามิเตอร์ การกำหนดค่า (Configuration)
Model Identifier gemini-1.5-flash (รองรับผ่าน Google GenAI SDK หรือ REST API)
ผู้พัฒนา Google DeepMind
บทบาท ทำงานเป็น Fallback อัตโนมัติเมื่อกำหนดค่า AI_PROVIDER=gemini หรือเมื่อระบบต้องการทางเลือกสำรองความเร็วสูง
กลไก Automated Validation Loop:
หลังจาก AI สร้างแผนงานออกมา ระบบจะรันการตรวจสอบ 3 มิติ (Completeness, Logic Flow & Circular Dependencies, Timeline Limits) หากตรวจพบข้อผิดพลาด ระบบจะส่ง Feedback ย้อนกลับไปให้ AI แก้ไขอัตโนมัติ (Retry สูงสุด 3 ครั้ง) เพื่อให้มั่นใจว่าแผนงานมีคุณภาพสูงสุดก่อนส่งถึงมือนักศึกษา

ส่งข้อมูลการบ้านที่ได้รับมอบหมายออกมาเป็น JSON Array ของ Assignment Objects:

  "id": "896521045888",
  "course_id": "896495436708",

  "title": "ออกแบบโลโก้หลักการ Gestalt",
  "description": "ให้นักศึกษาออกแบบโลโก้โดยประยุกต์ใช้หลักการจิตวิทยา Gestalt พร้อมอธิบายแนวคิด",

คำอธิบายฟิลด์สำคัญ:

  • id: รหัสอ้างอิงการบ้านจริงจาก Google Classroom (นำไปใช้เป็น Parent ID ในฐานข้อมูล)

  • is_processed: ตัวระบุสถานะว่าการบ้านชิ้นนี้เคยถูกสร้างแผนงานและบันทึกลงระบบแล้วหรือไม่
